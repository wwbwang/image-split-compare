# Image Split Compare

独立的只读图片目录对比服务。页面保留 A/B 主画面、并排与重叠分割、Patch 框选和可选 LQ / GT 切换。

## 使用

在顶部选择 A、B 图片目录开始对比，可添加 C、D 形成三图或四图对比。LQ 和 GT 可选，供各对比栏切换参考图。目录弹窗从容器的 `/` 逐级浏览，也可输入容器内绝对路径并点击“跳转”。只读取所选目录中的直接图片文件，支持 PNG、JPEG、WebP 和 BMP；不会递归读取子目录。

点击“上一级”时，目录列表会自动滚到刚离开的子目录并聚焦该行，方便继续查看相邻目录。

A 目录的文件按文件名自然排序，B、C、D、LQ 和 GT 按大小写完全一致的文件名配对。缺图时显示占位，不影响切换。点击“上一张 / 下一张”或按 `←` / `→` 切图；首尾自动停止。可在主画面拖拽框选 Patch。URL 的 `a`、`b`、`lq`、`gt`、`file` 参数会恢复目录和当前图片。

各栏切换来源的前进/后退键分别是 A：`1` / `4`，B：`2` / `5`，C：`3` / `6`，D：`7` / `8`。前进按「原图 → LQ → GT → 原图」循环，后退按相反顺序循环。参考图不可用时，该栏继续显示原图。

主图和 Patch 预览均支持「并排对比」和「重叠分割」。两图并排为两列，三图为一行三列，四图为 2×2（A、B 在上，C、D 在下）。重叠时，两图用一条竖线，三图用从交点伸出的三条射线，四图用十字分割。分割线只出现在图片共同覆盖的范围内，直接拖动任一线段即可移动整组分割线。用 Tab 聚焦分割线后可用方向键微调。URL 还会保存 C、D 的目录选择。

「隐藏 C / D」会保留目录选择，并让主图和 Patch 回到三图或双图布局。隐藏期间不再为该栏加入新的图片下载，已排队的图片继续下载；点「显示 C / D」后再按需加载当前图片。清除目录则会移除选择。URL 的 `hide` 参数记录隐藏状态。

## 本机图片缓存

图片首次查看时下载，之后保存在当前浏览器的本机缓存中。**同一浏览器配置文件、同一访问地址下的所有目录和标签页，共用总计 10 GiB 的磁盘图片缓存**，不是每个目录或页面各有 10 GiB。上限按图片字节计量，不包含浏览器的索引及存储管理开销。每个页面另有约 128 MiB 的图片字节内存缓存；当前使用的图片受到内存保护，因此这不是浏览器进程的总内存上限。各栏共用同一份 LQ 或 GT 图片数据，同一页面中同一张图片的并发请求也会合并。

磁盘缓存按最近最少使用（LRU）淘汰：命中内存或磁盘都会更新持久化访问顺序，刷新或重开页面后仍保留。所有标签页通过浏览器锁协调缓存写入、清理与容量统计，界面显示共享缓存的总量。磁盘条目被淘汰不会移除其他页面正在显示的内存图片。

切图时，访问过但尚未缓存的图片会按顺序加入下载队列，每个页面最多同时下载 3 张；离开当前图片不会取消其下载。例如从第 1 张快速切到第 11 张，1～11 对应的可见对比栏图片及已选择的 LQ / GT 都会继续下载并缓存，主画面只显示当前选中的第 11 张。相同图片不会在同一页面重复排队，已有缓存直接加载，无需等待下载队列。缓存数量、容量和本页面的“下载中／排队中”数量会动态更新。

队列在页面保持打开时运行；刷新或关闭页面后，尚未完成的队列不会恢复，已写入的缓存仍保留。点击“清除缓存”会同时取消正在下载和排队的任务。

已有图片缓存会被保留，首次升级只扫描一次已有缓存来建立共享索引；后续打开页面直接读取索引，不再逐张扫描。若写入时页面意外退出，下次使用会自动核对并恢复索引。升级后请刷新所有已打开的旧版页面，使其使用新的共享规则。

选择目录时一次读取图片索引，之后切图不再逐张请求元数据。刷新或重开页面后，仍可使用已存储的图片字节。缓存以目录、文件名、文件修改时间和文件大小区分版本；服务器图片有更新时，点击“刷新图片”重新读取目录与版本。“清除缓存”清除该网站所有目录共用的图片缓存，并通知其他标签页；当前显示的图片保留到下次切换。清除前开始的下载不会重新写回磁盘缓存。

缓存属于当前浏览器配置文件和访问地址（协议、主机名、端口）；不同浏览器、不同配置文件或不同地址的配额无法合并，`localhost` 与 `127.0.0.1` 的缓存不共用。建议固定使用同一个地址。10 GiB 是应用上限，不是预先占用或浏览器保证提供的空间。浏览器未允许持久存储、清理网站数据或磁盘空间不足时，磁盘缓存可能被清理；配额不足时会先淘汰旧图片再重试，仍失败会在页面提示。不支持 Cache Storage、IndexedDB 或 Web Locks 时自动使用内存缓存；持久缓存需要 HTTPS 或浏览器信任的本机地址。

## 启动服务

```bash
cd /opt/data/private/workspace/codes/video-compare-local
uv run --no-project --python 3.14 server.py \
  --host 127.0.0.1 \
  --port 8801 \
  --image-root /
```

`--image-root` 默认是 `/`，可设置成更小的可读目录。服务只监听容器内 `127.0.0.1:8801`。容器没有对外发布的端口时，可通过远程编辑器的 Ports 面板转发 8801，或使用现有 SSH 连接：

```bash
ssh -N -L 8801:127.0.0.1:8801 <container-ssh-destination>
```

之后在本机打开 <http://127.0.0.1:8801/>。服务只提供 `GET` 和 `HEAD`，不会修改、复制或迁移图片。由于默认根目录为 `/`，拥有端口访问权限的人可以读取容器内服务进程有权读取的支持格式图片；需要限制范围时设置 `--image-root`。
