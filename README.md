# Image Split Compare

独立的只读图片目录对比服务。页面保留 A/B 主画面、并排与重叠分割、Patch 框选和可选 LQ / GT 切换。

## 使用

在顶部选择 A、B 图片目录开始对比，可添加 C、D 形成三图或四图对比。LQ 和 GT 仍可选，用作 A、B 的快捷替换。目录弹窗从容器的 `/` 逐级浏览，也可输入容器内绝对路径并点击“跳转”。只读取所选目录中的直接图片文件，支持 PNG、JPEG、WebP 和 BMP；不会递归读取子目录。

A 目录的文件按文件名自然排序，B、LQ 和 GT 按大小写完全一致的文件名配对。缺图时显示占位，不影响切换。点击“上一张 / 下一张”或按 `←` / `→` 切图；首尾自动停止。按 `1` / `2` 分别在 A / B 画面切换 LQ，按 `3` / `4` 分别在 A / B 画面切换 GT；同一侧的 LQ 和 GT 互斥。可拖动主画面或 Patch 的分割线，也可在主画面拖拽框选 Patch。URL 的 `a`、`b`、`lq`、`gt`、`file` 参数会恢复目录和当前图片。

主图和 Patch 预览均支持「并排对比」和「重叠分割」。两图并排为两列，三图为一行三列，四图为 2×2（A、B 在上，C、D 在下）。重叠时，两图用一条竖线，三图用从交点伸出的三条射线，四图用十字分割。分割线只出现在图片共同覆盖的范围内，直接拖动任一线段即可移动整组分割线。用 Tab 聚焦分割线后可用方向键微调。URL 还会保存 C、D 的目录选择。

「隐藏 C / D」会保留目录选择，并让主图和 Patch 回到三图或双图布局。隐藏期间暂停该栏的图片下载，点「显示 C / D」后再按需加载当前图片。清除目录则会移除选择。URL 的 `hide` 参数记录隐藏状态。

## 本机图片缓存

图片首次查看时下载，之后保存在当前浏览器的本机缓存中。磁盘缓存上限约 4 GB，内存缓存上限约 128 MB；当前画面使用的图片会保留，超过容量时自动移除较早使用的缓存。LQ 和 GT 的两侧共用同一份图片数据，同一张图片的并发请求也会合并。

选择目录时一次读取图片索引，之后切图不再逐张请求元数据。刷新或重开页面后，仍可使用已存储的图片字节。缓存以目录、文件名、文件修改时间和文件大小区分版本；服务器图片有更新时，点击“刷新图片”重新读取目录与版本。“清除缓存”只清除该网站的本机图片缓存，当前显示的图片保留到下次切换。

缓存属于当前浏览器和访问地址；`localhost` 与 `127.0.0.1` 的缓存不共用。建议固定使用同一个地址。浏览器未允许持久存储、清理网站数据或磁盘空间不足时，磁盘缓存可能被清理；不支持本机存储时自动使用内存缓存。

## 启动服务

```bash
cd /opt/data/private/workspace/codes/video-compare-local
uv run --no-project --python 3.14 server.py \
  --host 127.0.0.1 \
  --port 8801 \
  --image-root /
```

`--image-root` 默认是 `/`，可设置成更小的可读目录。服务只监听容器内 `127.0.0.1:8801`。容器没有对外发布的端口时，可通过远程编辑器的 Ports 面板转发 8801，或使用现有 SSH 连接：

```bash
ssh -N -L 8801:127.0.0.1:8801 <container-ssh-destination>
```

之后在本机打开 <http://127.0.0.1:8801/>。服务只提供 `GET` 和 `HEAD`，不会修改、复制或迁移图片。由于默认根目录为 `/`，拥有端口访问权限的人可以读取容器内服务进程有权读取的支持格式图片；需要限制范围时设置 `--image-root`。
